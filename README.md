# polegarh.github.io

Personal site: a fogged sauna window you can wipe, then who I am and what I'm building.

```
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # outputs dist/
```

Pushes to `gh-pages` build and deploy through `.github/workflows/deploy.yml`. Repo Settings → Pages → Source must be **GitHub Actions**.
